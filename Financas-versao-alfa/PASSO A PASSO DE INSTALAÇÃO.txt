PASSO A PASSO DE INSTALAÇÃO 

1- Baixe o MySQL no terminal Linux-Ubuntu https://www.youtube.com/watch?v=Uuw4KPiVATc
2- Depois de baixar insira o comando CREATE DATABASE financas
3- Insira o comando USE financas
4- COMANDO MYSQL PARA CRIAR USUÁRIO ROOT:   CREATE USER IF NOT EXISTS 'financas_app'@'localhost' IDENTIFIED BY 'SuaSenhaForte123'; 
No lugar de SuaSenhaForte123 CRIE UMA SENHA PARA SUBSTITUIR.
5- DAR PERMISSÃO AO USUÁRIO: GRANT ALL PRIVILEGES ON financas.* TO 'financas_app'@'localhost';
6- APLICAR AS PERMISSÕES: FLUSH PRIVILEGES;

---------------------------------------------------------------------------------------------------------------------------------------

7- Extrair os arquivos Financas-app e financas-email-api
8- Acesse o arquivo financas-email-api
9- Clique no arquivo src
10- Clique no arquivo main
11- Clique no resources
12- Clique no editor de texto
13- Crie um arquivo com o nome application.properties



14- # Copie este arquivo para "application.properties" e preencha com seus dados reais.
# NUNCA suba o application.properties (com senha de verdade) para o GitHub.

spring.datasource.username=financas_app
spring.datasource.password= SUA_SENHA_FINANCAS_APP
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true

--------------------------------------------------------------------------------------------------------------------------------------------

21- Abra o terminal do Linux-Ubuntu
22- Transfira o financas-email-api e financas-app para Pasta pessoal
23- Insira o comando cd ~/financas-email-api
24- Insira o mvn spring-boot:run
25- Clique em novo terminal ou New Terminal
26- Insira o comando cd ~/financas-app
27- Insira o comando npm install
28- Insira o comando cd ~/financas-app && npm start
29- Espere executar
