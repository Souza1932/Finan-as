
## 🇧🇷 Português

Finanças

Finanças é um sistema projetado para ajudar na organização e no gerenciamento das suas contas, contribuindo para uma boa gestão financeira.

Devido à dificuldade que muitas pessoas enfrentam para administrar o dinheiro no dia a dia, o objetivo do sistema é ser uma ferramenta de apoio à organização financeira pessoal, permitindo registrar e acompanhar todas as despesas.



## Tecnologias utilizadas

* Java
* Spring Boot
* MySQL
* JavaScript
* HTML
* CSS
* Node.js
* Maven
* Claude
* Gemini
* Figma


## Funcionalidades 

* Cadastro de despesas
* Gráfico 
* opções de gráficos: barras, linhas, rosca e radar
* Registro de saldo: entrada e saída de dinheiro
* Planilha
* Espaço para definir metas de gastos e reserva de emergência.
* Calculadora

## ARQUIVOS

Financas.email.api é servidor do sistema finanças, sem ele o sistema não funciona.
Financas-app é arquivo que contém o sistema finanças.

🇺🇸 English

# Finances

Finances is a system designed to help organize and manage your accounts, contributing to sound financial management.

Due to the difficulty many people face in managing their daily money, the system's objective is to serve as a support tool for personal financial organization, allowing users to record and track all expenses.

---

##  Technologies Used

* Java
* Spring Boot
* MySQL
* JavaScript
* HTML
* CSS
* Node.js
* Maven
* Claude
* Gemini
* Figma

---

## Features

* Expense registration
* Charts: bar, line, donut, and radar chart options
* Balance tracking: income and expense entries
* Spreadsheet
* Dedicated space to set spending goals and emergency funds
* Calculator

---

## Files

* **Financas.email.api:** The server for the Finances system (required for the system to run).
* **Financas-app:** The repository file/folder containing the main Finances application.
